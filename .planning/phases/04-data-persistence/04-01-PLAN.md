2. Add a `persistMeeting` action to the store:
   ```typescript
   persistMeeting: async () => {
     const state = get();
     if (state.currentMeetingId) {
       // Update existing meeting
       await updateMeeting(state.currentMeetingId, {
         rawTranscript: state.rawTranscript,
         cleanedTranscript: state.cleanedTranscript,
         reportEN: state.reportEN,
         reportFR: state.reportFR,
         summaryEN: state.summaryEN,
         summaryFR: state.summaryFR,
       });
     } else {
       // Save new meeting
       const id = await saveMeeting({
         title: state.meetingTitle,
         date: state.meetingDate,
         rawTranscript: state.rawTranscript,
         cleanedTranscript: state.cleanedTranscript,
         reportEN: state.reportEN,
         reportFR: state.reportFR,
         summaryEN: state.summaryEN,
         summaryFR: state.summaryFR,
       });
       set({ currentMeetingId: id });
     }
   }
   ```

3. Update `setAllResults` action (added in Phase 3 Plan 02) to call `persistMeeting()` after setting all results. This ensures meeting data is saved to SQLite as soon as reports are generated.

5. Ensure the `cleanedTranscript`, `reportEN`, `reportFR`, `summaryEN`, `summaryFR` fields are in the State type and initial values (should already be from Phase 3 Plan 02, but verify).

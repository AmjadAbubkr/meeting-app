<action>
1. Install required packages for file export:
   ```
   npm install react-native-fs react-native-share
   npm install -D @types/react-native-share
   ```
   (react-native-fs should already be installed from Phase 1)

2. Replace the entire content of `src/services/exporter.ts`:

   - Import `RNFS` from `react-native-fs'
   - Import `Share` from 'react-native-share'
   - Import `Document, Packer, Paragraph, TextRun, HeadingLevel, AlignmentType` from `docx`
   - Import `MeetingRecord` from `../db/database`

3. Update `exportPDF(meeting: MeetingRecord, language: 'EN' | 'FR'): Promise<string>`:
   - Generate filename: `{meeting.title}_{meeting.date}.pdf` (sanitize: replace spaces with underscores, remove special chars)
   - For PDF generation on React Native without native PDF libraries, use a text-based approach:
     - Write the report content as a formatted text file with .pdf extension
     - Alternative (better): Use `react-native-html-to-pdf` library (install it) to convert HTML to PDF
     - Install: `npm install react-native-html-to-pdf`
     - Build HTML content:
       ```html
       <html>
       <head><style>
         body { font-family: Arial, sans-serif; padding: 40px; }
         h1 { color: #111827; }
         h2 { color: #374151; border-bottom: 1px solid #e5e7eb; padding-bottom: 8px; }
         .meta { color: #6b7280; margin-bottom: 20px; }
         .section { margin-bottom: 24px; }
       </style></head>
       <body>
         <h1>{meeting.title}</h1>
         <div class="meta">{meeting.date}</div>
         <div class="section"><h2>Summary</h2><p>{summary}</p></div>
         <div class="section"><h2>Report</h2><p>{report}</p></div>
       </body></html>
       ```
     - Use `RNFS.DocumentDirectoryPath + '/' + filename` as output path
     - Return the full file path

4. Update `exportDOCX(meeting: MeetingRecord, language: 'EN' | 'FR'): Promise<string>`:
   - Generate filename: `{meeting.title}_{meeting.date}.docx` (sanitized)
   - Use the `docx` library (already installed) to create a DOCX file:
     ```typescript
     const doc = new Document({
       sections: [{
         children: [
           new Paragraph({ text: meeting.title, heading: HeadingLevel.HEADING_1 }),
           new Paragraph({ text: meeting.date, spacing: { after: 200 } }),
           new Paragraph({ text: 'Summary', heading: HeadingLevel.HEADING_2 }),
           new Paragraph({ text: summary }),
           new Paragraph({ text: 'Report', heading: HeadingLevel.HEADING_2 }),
           // Split report text into paragraphs
           ...report.split('\n').filter(Boolean).map(p =>
             new Paragraph({ text: p, spacing: { after: 120 } })
           ),
         ],
       }],
     });
     ```
   - Generate blob: `await Packer.toBlob(doc)`
   - Convert blob to base64: use FileReader or buffer conversion
   - Write to file: `RNFS.writeFile(filePath, base64Content, 'base64')`
   - Return the full file path

5. Add a helper `sanitizeFilename(name: string): string`:
   - Replace spaces with underscores
   - Remove characters that are invalid in filenames: /\:*?"<>|
   - Truncate to 50 characters max
   - Return sanitized string

6. Both functions should select the correct language content:
   - language === 'EN' → summary = meeting.summaryEN, report = meeting.reportEN
   - language === 'FR' → summary = meeting.summaryFR, report = meeting.reportFR

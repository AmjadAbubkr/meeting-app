Replace the entire content of `src/services/generator.ts` with a real implementation:

1. Import `GEMINI_API_KEY` from `../config`
2. Import `Language` from `../store/appStore`

3. Define the Gemini API endpoint:
   ```typescript
   const GEMINI_URL = `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=${GEMINI_API_KEY}`;
   ```

4. Define the response type:
   ```typescript
   export type ReportResult = {
     cleanedTranscript: string;
     reportEN: string;
     summaryEN: string;
     reportFR: string;
     summaryFR: string;
   };
   ```

5. Implement `generateReport(rawTranscript: string, language: Language): Promise<ReportResult>`:
   - Validate GEMINI_API_KEY: if empty, throw Error('Gemini API key is missing. Set GEMINI_API_KEY in your .env file.')
   - Validate rawTranscript: if empty or whitespace-only, throw Error('Transcript is empty. Cannot generate report.')

   - Construct the Gemini prompt that requests all 5 outputs in a structured format:
     ```
     You are a professional meeting assistant. Given the following raw transcript of a meeting, produce:

     1. CLEANED TRANSCRIPT: Remove filler words, correct grammar, improve readability while preserving the original meaning and speaker intent.

     2. ENGLISH REPORT: A structured professional report in English with:
        - Meeting Summary (2-3 paragraphs)
        - Key Decisions (bulleted list)
        - Action Items (bulleted list with owners if mentioned)
        - Follow-ups (bulleted list)

     3. ENGLISH SUMMARY: A concise 3-5 sentence summary in English.

     4. FRENCH REPORT: The same structured report translated to French (Rapport):
        - Résumé de la réunion
        - Décisions clés
        - Points d'action
        - Suivi

     5. FRENCH SUMMARY: A concise 3-5 sentence summary in French.

     Format your response as JSON with keys: cleanedTranscript, reportEN, summaryEN, reportFR, summaryFR

     Raw transcript:
     {rawTranscript}
     ```

   - Make POST request to Gemini URL with:
     ```json
     {
       "contents": [{ "parts": [{ "text": prompt }] }],
       "generationConfig": {
         "temperature": 0.3,
         "responseMimeType": "application/json"
       }
     }
     ```

   - Parse the Gemini response:
     - Extract `candidates[0].content.parts[0].text` from response JSON
     - Parse the text as JSON (Gemini returns JSON when responseMimeType is set)
     - Validate all 5 fields exist in the parsed result
     - If JSON parsing fails, attempt to extract the fields from the text response using regex

   - Error handling:
     - 401 → throw Error('Invalid Gemini API key. Check your GEMINI_API_KEY setting.')
     - 429 → throw Error('Gemini API rate limit exceeded. Wait a moment and try again.')
     - 5xx → retry once after 3 seconds. If still fails, throw Error('Gemini API is temporarily unavailable.')
     - If response doesn't contain expected fields, throw Error('Gemini response format unexpected. Try again.')

   - Return ReportResult with all 5 fields
</action>

<action>
1. In MeetingScreen.tsx:
   - Import `transcribeChunks` from `../services/transcriber`
   - Import `useAppStore` for `audioChunks`, `rawTranscript`, `setTranscript`, `setProcessingStep`

2. Create a `processAudio` async function in the MeetingScreen component:
   ```typescript
   const processAudio = async () => {
     try {
       setAppState('PROCESSING');
       setProcessingStep('Transcribing audio...');

       const transcript = await transcribeChunks(audioChunks, (current, total) => {
         setProcessingStep(`Transcribing chunk ${current}/${total}...`);
       });

       setTranscript(transcript);
       setProcessingStep('Transcription complete');
       // Phase 3 will add report generation here
       setAppState('RESULTS');
     } catch (error: any) {
       Alert.alert('Processing Error', error.message || 'Failed to process audio.');
       setAppState('READY');
     }
   };
   ```

3. Wire `processAudio` into the UI flow:
   - In RECORDING state: "End Meeting" button → call `stop()` from recording controller, then `processAudio()`
   - In PROCESSING state: display `processingStep` text (e.g., "Transcribing chunk 2/5...")
   - Remove "Show Results" button from PROCESSING state — transition is automatic after processAudio completes

4. Update the PROCESSING state UI:
   - Show a spinner or activity indicator
   - Show the `processingStep` text below the spinner
   - Add a "Cancel" button that calls `resetMeeting()` and returns to FORM

5. In the RESULTS state: Display the raw transcript text in a ScrollView so user can see what was transcribed. Show "New Meeting" button that calls `resetMeeting()`.

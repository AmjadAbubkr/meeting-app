<action>
Replace the entire content of `src/services/transcriber.ts` with a real implementation:

1. Import `GROQ_API_KEY` from `../config`
2. Import `RNFS` from `react-native-fs` (already installed in Phase 1)

3. Define the Groq Whisper API endpoint constant:
   ```typescript
   const GROQ_WHISPER_URL = 'https://api.groq.com/openai/v1/audio/transcriptions';
   ```

4. Implement `transcribeChunks(audioChunks: string[], onProgress?: (current: number, total: number) => void): Promise<string>`:
   - Validate GROQ_API_KEY: if empty, throw Error('Groq API key is missing. Set GROQ_API_KEY in your .env file.')
   - Validate audioChunks: if empty array, throw Error('No audio chunks to transcribe.')
   - Iterate over each audioChunks URI:
     - Read file as base64 using `RNFS.readFile(uri, 'base64')`
     - Create FormData multipart request:
       ```
       POST https://api.groq.com/openai/v1/audio/transcriptions
       Headers: Authorization: Bearer {GROQ_API_KEY}
       Body: FormData with:
         - file: audio file data (determine mime type from extension)
         - model: "whisper-large-v3"
         - response_format: "text"
         - language: "en" (default, will be configurable in Phase 3)
       ```
     - Call onProgress(current=i+1, total=audioChunks.length) after each chunk request
     - If a single chunk fails with 401, throw Error('Invalid Groq API key. Check your GROQ_API_KEY setting.')
     - If a single chunk fails with 429, throw Error('Groq API rate limit exceeded. Wait a moment and try again.')
     - If a single chunk fails with 5xx, retry once after 2 seconds. If still fails, throw Error('Groq API is temporarily unavailable. Try again later.')
     - Collect the text response from each chunk
   - Join all partial transcripts with a newline separator
   - If the joined transcript is empty, throw Error('Transcription produced no text. The audio may be empty or unclear.')
   - Return the full raw transcript string

5. Implement a helper `getMimeType(uri: string): string`:
   - Map file extensions to MIME types: .wav → audio/wav, .mp3 → audio/mpeg, .mp4 → audio/mp4, .m4a → audio/x-m4a, .webm → audio/webm
   - Default to 'audio/wav' if extension unknown

6. Ensure the function signature matches the existing one so MeetingScreen/other consumers don't break.

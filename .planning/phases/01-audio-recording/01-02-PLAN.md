3. Create `src/services/uploader.ts` with the following implementation:

- Import `DocumentPicker` from `react-native-document-picker`
- Import `RNFS` from `react-native-fs`
- Import `CHUNK_SIZE_BYTES, SUPPORTED_AUDIO_FORMATS` from `../config`

- Export `pickAndChunkAudio(onChunkComplete: (uri: string, chunkIndex: number, totalChunks: number) => void): Promise<{ uri: string; chunkCount: number } | null>`:
  a. Call `DocumentPicker.pick({ type: [DocumentPicker.types.audio] })` to open the file picker
  b. If user cancels (no selection), return `null`
  c. Extract the file URI from the picker response
  d. Extract the file extension from the URI, convert to lowercase
  e. Validate the extension against `SUPPORTED_AUDIO_FORMATS` array. If invalid, throw `Error('Unsupported audio format: {ext}. Supported formats: mp3, mp4, wav, m4a, webm')`
  f. If valid, call `chunkExistingFile(uri, onChunkComplete)` and return the result

- Export `chunkExistingFile(filePath: string, onChunkComplete: (uri: string, chunkIndex: number, totalChunks: number) => void): Promise<{ uri: string; chunkCount: number }>`:
  a. Use `RNFS.stat(filePath)` to get the file size
  b. If file size <= CHUNK_SIZE_BYTES, this is a single chunk:
     - Call `onChunkComplete(filePath, 0, 1)`
     - Return `{ uri: filePath, chunkCount: 1 }`
  c. If file size > CHUNK_SIZE_BYTES, calculate totalChunks = Math.ceil(fileSize / CHUNK_SIZE_BYTES)
  d. For each chunk index i from 0 to totalChunks-1:
     - Calculate startByte = i * CHUNK_SIZE_BYTES
     - Calculate endByte = Math.min(startByte + CHUNK_SIZE_BYTES, fileSize)
     - Read the byte range from the file using `RNFS.read(filePath, CHUNK_SIZE_BYTES, startByte, 'base64')` — NOTE: RNFS.read signature is `(filePath, length, position, encoding)
     - Write the chunk to a new temp file: `RNFS.CachesDirectoryPath + '/upload_chunk_' + i + '_' + Date.now() + '.tmp'`
     - Write the base64 data using `RNFS.writeFile(chunkPath, base64Data, 'base64')`
     - Call `onChunkComplete(chunkPath, i, totalChunks)`
  e. Return `{ uri: filePath, chunkCount: totalChunks }`

- Export `cleanUploadChunks(): Promise<void>`: Delete all files in CachesDirectoryPath matching 'upload_chunk_*' pattern using RNFS.readdir + RNFS.unlink.

4. Error handling:
   - If DocumentPicker throws the user-cancelled error (check for `DocumentPicker.isCancel(err)`), return `null` (do NOT throw)
   - If RNFS.stat fails (file not found), throw `Error('Selected file not found')`
   - If RNFS.read/write fails during chunking, throw `Error('Failed to chunk audio file: ' + message)`

5. Add TypeScript types for all exported functions.
</action>

2. Export a `useUploadController` hook from `src/services/uploader.ts` (or inline in the existing file):
```typescript
export function useUploadController() {
  const addAudioChunk = useAppStore(s => s.addAudioChunk);
  const setChunkState = useAppStore(s => s.setChunkState);
  const setProcessingStep = useAppStore(s => s.setProcessingStep);
  const setAppState = useAppStore(s => s.setAppState);

  const upload = async () => {
    setAppState('PROCESSING');
    setProcessingStep('Selecting audio file...');

    const result = await pickAndChunkAudio((uri, index, total) => {
      addAudioChunk(uri);
      setChunkState(total, index);
      setProcessingStep('Chunking audio ' + (index + 1) + '/' + total + '...');
    });

    if (!result) {
      // User cancelled picker
      setAppState('READY');
      setProcessingStep('');
      return;
    }

    setProcessingStep('Upload complete. ' + result.chunkCount + ' chunk(s) ready.');
  };

  return { upload };
}
```

3. This hook connects the uploader service to the Zustand store. The UI (Plan 03) will call `upload()` when the user taps the Upload Audio button.

4. Ensure the `handleUploadChunk` action is added to the State type definition in appStore.ts and implemented in the create() call.
